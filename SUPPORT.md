# Support

## Getting Help

If you run into issues or have questions, here are your options:

### 📖 Read the Docs First

- [Installation Guide](docs/installation.md)
- [Configuration Guide](docs/configuration.md)
- [Troubleshooting Guide](docs/troubleshooting.md)
- [FAQ](FAQ.md)

### 🐛 Found a Bug?

Open a [Bug Report](https://github.com/sabercodes/gibbon-image-zipper/issues/new?template=bug_report.md) on GitHub Issues.

Please include:
- Your Python and Pillow version
- Operating system
- Steps to reproduce
- Error output

### 💡 Have a Question?

Open a [Question](https://github.com/sabercodes/gibbon-image-zipper/issues/new?template=question.md) on GitHub Issues.

### 🔒 Security Issues

Do **not** open a public issue for security vulnerabilities. See [SECURITY.md](SECURITY.md) for responsible disclosure instructions.

---

## Response Times

This is a community-maintained open-source project. Maintainers aim to respond within a few days, but there are no guaranteed SLAs.
